Working in WorkLog

Notes by task
Organize Markdown and text notes in folders, create dated daily logs, and keep several notes open in tabs. View images, PDFs, and Mermaid diagrams alongside your writing.
Tasks and search
Find unfinished Markdown checkboxes in the task overview. Search note text across tasks, including closed tasks, and jump to matching lines.
Time and timesheets
Enter a duration or copy elapsed time from the timer. Select or create a project code inline. Correct earlier entries, review daily and project-code totals, and export a date range as Markdown.

Storage & backups

Read your data
with a text editor.

Notes are Markdown or UTF-8 text files. Time records are stored as JSON Lines in time.jsonl. You can read both with a text editor outside WorkLog. Images and PDFs keep their original formats.

Keep local Git history and back up to a folder or Git remote. Run backups manually or on a daily schedule while the app is open. Git history and remote backups require Git; remote backups use your existing SSH keys or credential helper.

Backup and restore instructions ↗

Ask an assistant about your work

Connect a compatible assistant through the read-only MCP endpoint to search saved notes, retrieve time entries, and inspect Git history. Use those records to summarize a period of work or draft a review. Sharing is off at launch; you start it in Settings. Authentication is required, with TLS for network connections unless you explicitly allow HTTP on a trusted private network.
